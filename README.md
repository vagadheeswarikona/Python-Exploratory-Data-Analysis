## Exploratory Data Analysis – Car Sales
### 📌 Overview:
Conducted exploratory data analysis on car sales data to understand sales trends, seasonality, and factors influencing demand.

### 🛠 Tools & Technologies:
1. Python
2. Pandas, NumPy (data preparation and transformation)
3. Matplotlib, Seaborn (data visualization)
4. Jupyter Notebook

### 🚀 Key Highlights:
1. Cleaned and transformed historical car sales data for analysis
2. Identified seasonal patterns and sales trends over time
3. Analyzed relationships between pricing, demand, and sales volume
4. Created visualizations to support forecasting and business insights

### 📈 Outcome:
Provided actionable insights into car sales behavior, enabling better planning and informed decision-making.
